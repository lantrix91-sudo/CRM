# Неделя 5 — клиенты и лиды

Откройте /leads/ или главную страницу /. Требуется вход сотрудника через /admin/login/.
Карточки показывают имя клиента, телефон, услугу, название обращения, источник, ответственного и статус.

## Новые поля Lead
- source: необязательный текст до 100 символов, например OLX, сайт или рекомендация.
- status: new (Новый), in_progress (В работе), won (Успешно завершён), lost (Закрыт без сделки).
Статус по умолчанию — Новый. Миграция сохраняет старые записи: источник пустой, статус новый.
Статусы пока меняются вручную, заказ автоматически не создаётся.

Клиент, телефон, услуга и сотрудник берутся из существующих связей; данные не дублируются в Lead.
У одного клиента могут быть несколько карточек: карточка представляет отдельный лид.

## Как создать карточку
1. В админке создайте клиента и услугу, если их ещё нет.
2. В /leads/ нажмите «Новый лид».
3. В форме админки укажите название, клиента, услугу, источник и статус; ответственный необязателен.
4. Сохраните и вернитесь в /leads/.
«Изменить» в карточке открывает форму этого лида в админке.
Пример из задания можно ввести вручную: Иван Петров, Ремонт холодильника, OLX, Сергей, Новый.
Демонстрационные клиенты автоматически в базу не добавляются.

## Доступ
Суперпользователь видит страницу сразу.
Обычному активному сотруднику нужны is_staff и права leads.view_lead, customers.view_client.
Это общая доска команды: сотрудник с этими правами видит все лиды, а не только назначенные ему.
Для кнопок создания и изменения нужны leads.add_lead и leads.change_lead соответственно.
Админка самостоятельно проверяет права на связанные модели при автодополнении.
Пообъектное распределение доступа пока не реализовано.

## Поиск
Поиск по имени, телефону, названию обращения, услуге и источнику.
Телефон ищется по введённой подстроке, без нормализации формата.
Фильтр по статусу можно сочетать с поиском. По 12 карточек на страницу, новые сверху.
Пустые источник и ответственный отображаются как «Не указан» и «Не назначен».

## Код
- models.py: новые поля и перечисление статусов.
- migrations/0002_lead_source_lead_status.py: изменение схемы.
- views.py: проверка прав, поиск, фильтрация и пагинация.
- urls.py: маршрут /leads/.
- templates/leads/lead_list.html: HTML карточек.
- static/leads/cards.css: адаптивное оформление.
- admin.py: поля и фильтры админки.
- tests.py: доступ, данные карточки, поиск, пагинация и экранирование HTML.

```powershell
.\.venv\Scripts\python.exe backend/manage.py migrate
.\.venv\Scripts\python.exe backend/manage.py test apps.leads apps.orders --noinput
.\.venv\Scripts\python.exe backend/manage.py runserver
```
