# API мастера

Базовый путь: /api/mobile/. JSON, денежные суммы передавать строками.
Авторизация всех маршрутов, кроме login: Authorization: Bearer <token>.
Токены не помещать в URL. Сессии хранятся в accounts.MobileSession только как SHA-256 digest.

POST login/ — username, password. Только активный worker, без superuser.
Ответ: token, name. Ограничение: 10 попыток в минуту по IP.
POST logout/ — отзывает текущую сессию.
GET profile/ — имя, процент и финансовая сводка.
GET orders/?scope=active|history&page=1 — count, next, previous, results (20 записей).
GET orders/<id>/ — своя карточка и журнал событий.
POST orders/<id>/action/ — action и данные действия:

- start — принять и начать назначенный заказ.
- reject — вернуть ещё не принятый заказ оператору.
- preview — amount, expenses, comment. Возвращает расчёт и подписанный confirmation.
- complete — confirmation. Подтверждение действует 15 минут, привязано к заказу,
  мастеру и текущему проценту. Повторное завершение не создаёт повторную оплату.
- payment — received_amount, received_method (cash/transfer/card), только для ожидающих оплату.

Ошибки: 400 — поля, 401 — вход/сессия, 403 — роль, 404 — заказ отсутствует/чужой,
409 — устаревший этап или бизнес-ограничение, 429 — лимит входа.

API использует общие сервисы заказов и транзакции. Для отказа и получения старой оплаты
сохранены правила веб-кабинета, включая деактивацию уведомлений при отказе.
Изменение назначения, зарплатных процентов, переводов и закрытие смены в мобильном API отсутствуют.
