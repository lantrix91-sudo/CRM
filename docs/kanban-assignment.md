# Единая доска работы

Новый → В работе → Назначен → Завершён → Оплачен.

- Новый: обращение без заказа. Оператор нажимает «Клиент согласился». Создаётся один заказ, карточка остаётся на доске.
- В работе: согласие получено, требуется мастер. Можно выбрать доступного мастера по услуге или автоматический подбор. Сервер проверяет загрузку.
- Назначен: заказ передан мастеру. Подпись различает ожидание принятия и начало работы.
- Завершён: назначенный мастер подтвердил окончание через кабинет или Telegram.
- Оплачен: руководитель подтвердил получение оплаты на странице заказа после указания положительной суммы. Способы оплаты пока не добавлены.

После отказа мастера заказ возвращается в «В работе». Произвольная смена статуса в канбане запрещена. Доска обновляется каждые 15 секунд и по кнопке. Подробности и журнал доступны через «Заказ и история».

История записывает новые подтверждения согласия, назначения, принятия, завершения и оплаты с автором и временем. Прошлые события не восстанавливаются вымышленными записями. Старые лиды без заказа показываются в «Новых» независимо от прежнего вручную выставленного статуса; данные сохраняются. При согласии ранее выбранный активный мастер переносится в заказ.
